# Fixtures

Copied unchanged from `hampel/saasu-api`'s own suite, 0.4.0, whose fixtures follow Saasu's
documented response for each endpoint. Several hold Saasu's documentation placeholders
(`bank-balances.json` is all "sample string"), so they prove shape, not values.

**Replace one with a capture from a real file when a tool's presentation starts depending on a
value**, with ids and names replaced. A fixture written from the code that reads it can only agree
with that code.
